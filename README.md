# sediment-classification-folk-ward-shepard

Ternary Diagrams for Sediment Classification (Folk & Shepard)
📌 Description
This project implements the graphical construction and data visualization of two widely used sediment classification diagrams:  Folk Diagram (Gravel–Sand–Mud)  Shepard Diagram (Sand–Silt–Clay)  Both diagrams are generated using Python and allow plotting real sample data loaded from Excel files.
